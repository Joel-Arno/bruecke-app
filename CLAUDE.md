# Projekt: Kfz-Elektrik-Trainer (Arbeitstitel)

Kleines Nebeneinkommen mit einem bezahlten Web-Tool.
Wenige Stunden pro Woche, kleines Budget.

- Baue Web-Apps mit Claude Code: schlank, wenige Dateien, gutes Design

## Entscheidungen
- **Nische:** Kfz-Mechatroniker-Azubis, Deutsch (DACH)
- **Produkt:** Lern- und Übungstrainer für Kfz-Elektrik (kein reiner Rechner)
- **Stufen pro Thema:** Verstehen → Üben (Lösungsweg Schritt für Schritt) → Prüfung (mit Timer)
- **Version 1:** Ohmsches Gesetz, Leistung, Reihen-/Parallelschaltung,
  Spannungsfall + Quiz zu Klemmenbezeichnungen
- **Später:** V2 Messen (virtuelles Multimeter), V3 Schaltpläne lesen,
  danach mechanische Formeln
- **Aufgaben:** automatisch mit Zufallswerten erzeugt; keine Prüfungsfragen kopieren
- **Schreibweise:** Formelzeichen und Einheiten wie im
  „Tabellenbuch Kraftfahrzeugtechnik“ (Europa-Lehrmittel)
- **Geräte:** vor allem iPad/Tablet, dazu Handy; offline nutzbar,
  zum Home-Bildschirm hinzufügbar
- **Verkauf:** kostenlos online gehostet; Gratis-Teil + Vollversion per
  Lizenzschlüssel (Gumroad oder Lemon Squeezy). Freischaltung: einmal
  Code eingeben, kein Konto, keine nervigen Hinweise
- **Preis:** ca. 5–15 €, „Early Access – alle Updates inklusive“
- **Marketing:** TikTok/Shorts ohne Gesicht (Bildschirmaufnahmen)
- **Verworfen:** Etsy, Berichtsheft-Tool, reiner Rechner, Gaming/CoC

## Arbeitsregeln
- Immer auf Deutsch antworten
- Kein Code und keine Dateiänderungen ohne ausdrückliches „ja, mach das“
- Ehrlich sagen, wenn eine Idee wenig Chancen hat; Alternativen vorschlagen

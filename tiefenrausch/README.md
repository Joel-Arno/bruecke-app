# Tiefenrausch

Ein Offline-Handyspiel: Steuere ein Tauchboot 10.994 m tief bis zum Grund des Marianengrabens.

- **Ziehen** irgendwo auf dem Bildschirm steuert das Tauchboot.
- **Leuchtplankton** lädt deine Scheinwerfer auf. Ohne Licht bist du im Dunkeln fast blind.
- **Sonar** (Knopf rechts unten oder zweiter Finger) zeigt kurz Wände und Gefahren.
- Quallen, Felsbrocken, Seeminen und Anglerfische kosten Hülle. Nach drei Treffern ist der Tauchgang vorbei.
- Knapp an Gefahren vorbei lädt dein Licht ein wenig auf.

Am Computer: Pfeiltasten oder WASD zum Steuern, Leertaste für Sonar, `P` für Pause.

## Offline spielen

Das Spiel ist eine einzige HTML-Datei ohne externe Abhängigkeiten. Wird der Ordner über HTTPS
ausgeliefert (z. B. GitHub Pages), speichert ein Service Worker alles auf dem Gerät. Einmal öffnen,
dann „Zum Home-Bildschirm hinzufügen“ – danach läuft es ohne Internet.

Rekorde werden nur lokal im Browser gespeichert.
